BFS: breadth first search

- this algo is used to travserse the graph in level order
- this algo uses queues data structure to store the nodes to be visited
- this algo uses visited array to keep track of the nodes that have been visited.
- time complexity: O(V + E)
- space complexity: O(V)


DFS: depth first search

- this algo is used to travserse the graph in depth order (preorder traversal)
- this algo uses stack data structure to store the nodes to be visited
- this algo uses visited array to keep track of the nodes that have been visited.
- time complexity: O(V + E)
- space complexity: O(V)


Both the problems can be solved in below possibles ways:
1. using recursion
2. using recursion with memoization
3. using iteration
4. using stack
5. using queue
6. using priority queue
7. using disjoint set union (DSU)
8. using topological sort
9. using backtracking
10. using dynamic programming
